About the job
Come be a part of our mission and make a meaningful and positive impact with the industry leading provider of language services for the Deaf and hard-of-hearing!

Job Summary
As a Software Developer Intern, you will design and build an automated data-ingestion pipeline that integrates information from an external system into an internal platform. This project will replace a manual process and establish a reusable framework for future integrations. This is a hands-on development role where you will own a meaningful engineering challenge from design through implementation. You'll work closely with an experienced mentor while gaining exposure to production-quality software development practices, including reliability, monitoring, scheduling, logging, and error handling.

Pay Range: $20-30/hr DOE
Duration: Three months

Essential Duties And Responsibilities
Analyze, document, and understand external APIs, including authentication methods, endpoints, metadata structures, and data availability.
Design scalable data-ingestion workflows that automate the transfer of information between systems.
Map and transform metadata from external sources into internal platform requirements.
Develop and implement integration logic, including data validation and record eligibility rules.
Build automated processes that can be scheduled or event-driven based on business requirements.
Implement logging, monitoring, retry mechanisms, and error-handling capabilities to support reliable operation.
Test, troubleshoot, and optimize data pipelines to ensure accuracy and performance.
Create technical documentation and implementation guides for future integrations.
Collaborate with engineering team members and participate in code reviews and technical discussions.
Utilize AI-assisted and agentic development tools to accelerate software delivery while maintaining code quality and engineering best practices.

Essential AI-Assisted Development Experience
At Sorenson, we embrace modern software development practices, including the use of AI-powered coding tools. Throughout this internship, you will gain practical experience:
Creating clear technical specifications for AI-assisted development workflows.
Using agentic coding tools to accelerate API exploration, documentation, and implementation tasks.
Reviewing, testing, validating, and refining AI-generated code.
Applying engineering judgment to ensure quality, maintainability, and reliability.
Learning industry-leading approaches to AI-enabled software engineering.
No prior experience with AI coding tools is required. A willingness to learn and adapt is essential.
